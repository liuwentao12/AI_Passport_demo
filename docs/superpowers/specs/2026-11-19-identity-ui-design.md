# 身份卡界面设计

用户已选择 LVGL 和分层方案。首版沿用现有 ESP32、ILI9341、240×320 竖屏及已验证引脚；不改变麦克风测试。上电显示身份卡，详情页展示完整资料，所有数据明确为演示数据。

## 方案比较
- 直接绘图：依赖少，但后续文字、控件和交互需自行维护。
- LVGL：用户选择。页面、主题、数据模型、驱动分离，便于继续开发。

## 实现决定
- 固定 LVGL 9.3.0，ESP-IDF component manager 管理依赖。
- board 管理 SPI/LCD 和触摸接口；ui/port 适配 LVGL tick、刷屏和输入；ui/pages 只创建控件；app 管理启动和跨任务数据更新。
- 单 UI 任务拥有所有 LVGL 对象。其他任务仅通过 app_set_identity() 拷贝数据到长度为 1 的覆盖队列，显示最新资料。
- 单块 240×20 RGB565 DMA 缓冲（9600 字节），刷屏等待 DMA 完成再通知 LVGL复用。启动错误 fail-fast，不支持运行时卸载驱动。
- 卡片为浅色背景、深色顶栏、青绿色强调色，头像使用姓名缩写，提供身份卡/详情切换。首版英文文字使用内置字体；中文需后续添加字库。
- 触摸芯片型号未知：明确返回未按下，保留 lv_indev 适配链，界面提示 TOUCH NOT CONFIGURED；不猜芯片或校准参数。
- 不声称已联网、已验证身份或已接入录音；不自动烧录。

## 验证
目标固件构建；主机身份数据边界测试；基于真实 LVGL 的页面切换和尺寸测试、离屏渲染；上板检查颜色、方向和显示稳定性留给用户。硬件触摸待型号确认。
