# XPT2046 接入计划

目标：按用户确认的接线接入 XPT2046，支持身份卡导航和详情滚动。

- SPI2 共用 SCK=18、MOSI=23、MISO=19；触摸 CS=17；PEN 未接。
- 轮询 Z1/Z2 判断按压，1 MHz、mode 0、12 位差分转换，多次采样取中值；不重复初始化 SPI 总线。
- 使用三点仿射校准处理轴交换、方向和实际 ADC 范围，再点中心验证；有效参数保存到独立 NVS namespace。用户无需猜测原始坐标范围。
- 校准期间保留单 UI 任务，尚未校准不向 LVGL 注入触摸；正常页面启动前完成校准，避免校准点击穿透。
- 持久化失败仅本次生效，不擦除整个 NVS；提供配置开关重新校准。
- 实现纯坐标变换单元测试源码，移除旧“驱动永远不可用”的主机测试依赖。
- 用户明确不代为编译：只静态检查，不构建、不运行编译型测试、不烧录。

验证重点：SPI 帧对齐、CS 管理、松手事件、边缘裁切、校准点退化/方向变化、NVS 数据格式和校准结束后释放。

实施结果：驱动、三点校准与中心验证、NVS 保存、LVGL 输入接入和坐标变换测试源码已完成。旧主机 UI 测试已解除对硬件驱动的依赖。依据本地 ESP-IDF/LVGL 头文件核对接口及初始化顺序，独立只读审查未发现重要缺陷。遵循用户要求未编译、未运行新增测试、未烧录；压力阈值、点击/滑动体验、坐标精度及断电后参数恢复待上板确认。
